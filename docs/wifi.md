# Wi-Fi tuning

NetRocket's Wi-Fi profile is driver-aware.

## Settings

### Transmit Power

Preferred value: `Highest`

### Roaming Aggressiveness

Preferred value: `Medium`

### Preferred Band

NetRocket tries 6 GHz first, then 5 GHz, when the driver exposes a compatible option.

This does not guarantee the adapter will always use that band.

### 5 GHz Channel Width

Preferred value: `Auto`

### Wireless Mode

Where supported, NetRocket tries 802.11ax before broader compatibility values.

## Wi-Fi 7

NetRocket does not currently force Wi-Fi 7-specific settings. A dedicated profile is planned once there is enough hardware and driver coverage to make it reliable.
